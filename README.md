# llm-month

A 30-day, project-based plan to become job-ready in LLM engineering (RAG, vector DBs,
LangChain/LangGraph, guardrails, observability) — designed to run completely free.

- **Start here:** [`PLAN.md`](./PLAN.md) — the master plan.
- **Daily tasks:** [`todos/`](./todos) — one `day-NN.md` per day (Day 01 = Sun May 31, 2026).
- **Track progress:** [`PROGRESS.md`](./PROGRESS.md).
- **Working in Claude Code?** It reads [`CLAUDE.md`](./CLAUDE.md) automatically.
- **Your code:** grows inside [`src/`](./src), one folder per project.

## Quick start (Day 1)
```bash
python -m venv .venv                 # create the virtual environment (once)
source .venv/bin/activate            # ACTIVATE it — Windows: .venv\Scripts\activate
# Activate it EVERY session before installing or running anything (prompt shows (.venv)).
pip install -r requirements.txt                     # you'll create this on Day 1
cp .env.example .env                                # then add your API key
```
Then open `todos/day-01.md` and go.
