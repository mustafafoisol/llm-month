# Project 1 — Mini-RAG (from scratch)

**Days 2-5.** Code for this project lives in this folder and grows day by day.

## Goal
Build semantic search + grounded answering by hand, with no framework.

## Definition of done
Ask a question, get an answer grounded in your snippets with sources shown; out-of-corpus questions say 'I don't know'.

See the matching `todos/day-NN.md` files for the daily task breakdown, and `PLAN.md` for the big picture.
